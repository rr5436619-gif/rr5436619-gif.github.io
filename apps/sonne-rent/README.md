# Sonne Rent — نظام تأجير السيارات

نظام ويب كامل لشركات تأجير السيارات، يعمل من المتصفح على الكمبيوتر والموبايل بواجهة عربية.
المطوّر: Rabie Al Mehtar — Sonne Apps

## الأقسام
صفحة حجز للعملاء · لوحة تحكم · الأسطول · حالة السيارات والصيانة · العملاء · الحجوزات ·
التسليم والاستلام · الفواتير والمدفوعات · بلاغات الحوادث · التنبيهات · التقارير · المستخدمون والصلاحيات · الإعدادات

## طريقتا التشغيل
1. **محلي (تجريبي):** افتح `index.html` مباشرة. البيانات تُحفظ في المتصفح على جهاز واحد.
   الدخول التجريبي: `admin / admin123`
2. **سحابي (لعدة أجهزة وموظفين):** عبر Supabase (الخطة المجانية تكفي للبداية).

## تجهيز نسخة لعميل جديد (الوضع السحابي)
1. أنشئ مشروعاً جديداً على supabase.com باسم شركة العميل (منطقة Frankfurt لعملاء ألمانيا).
2. SQL Editor ← الصق محتوى `setup.sql` ← Run.
3. Authentication ← Sign In / Providers ← **أوقف "Allow new users to sign up"** (مهم للأمان).
4. Authentication ← Users ← Add user: بريد وكلمة مرور المدير (فعّل Auto Confirm).
5. Project Settings ← API: انسخ `Project URL` و`anon public key`.
6. في `index.html` ضعهما في السطر:
   `const EMBED={url:'...',key:'...'};`
7. ارفع الملف على استضافة العميل (GitHub Pages أو أي استضافة).
8. أول دخول بالبريد في الخطوة 4 يصبح **مدير النظام** تلقائياً.
9. لكل موظف: أنشئ حسابه في Supabase (الخطوة 4)، ثم أضف بريده من قسم «المستخدمون والصلاحيات».

## ملاحظات
- مفتاح `anon` مسموح أن يكون علنياً؛ الحماية تتم بقواعد RLS في `setup.sql`.
  **لا تضع أبداً مفتاح `service_role` في الملف.**
- صفحة العملاء تحتاج Impressum وDatenschutzerklärung (من الإعدادات).
- الفواتير لا تُحذف؛ الإلغاء بفاتورة ستورنو.
- الدفع الإلكتروني عبر رابط PayPal.me أو Stripe Payment Link؛ لا يتم حفظ بيانات بطاقات.
